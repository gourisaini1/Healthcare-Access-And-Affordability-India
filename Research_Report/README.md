# Research Report

This directory contains the written research output for the project.

## Report contents

1. Research background and problem statement.
2. Research objectives and questions.
3. Data sources, definitions and coverage.
4. Methodology and analytical approach.
5. Results and visual evidence.
6. Economic interpretation and discussion.
7. Limitations.
8. Conclusions and policy implications.

The report will present findings only after the underlying analysis has been completed and validated. Source references and relevant methodological notes will be included.
