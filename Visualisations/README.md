# Visualisations

This directory stores the charts and figures generated by the project notebooks.

## Planned visual outputs

- Healthcare expenditure comparisons.
- Government and out-of-pocket health expenditure.
- State-wise healthcare infrastructure comparisons.
- Healthcare workforce indicators.
- Rural–urban comparisons, where comparable data are available.
- Statistical relationship plots and correlation heatmaps.

Figures will be added here after they have been generated from the documented source data and checked for accuracy. Each figure will include a descriptive filename and an explanation in the relevant notebook.
