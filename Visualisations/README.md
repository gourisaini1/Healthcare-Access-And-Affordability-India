# Visualisations

This directory contains the charts used in the project README and research report.

| File | Description |
|---|---|
| `01_financing_shares.svg` | National government and out-of-pocket financing shares |
| `02_total_health_expenditure_gdp.svg` | National total health expenditure as a share of GDP |
| `03_per_capita_expenditure.svg` | National nominal per-capita health expenditure |
| `04_social_security_private_insurance.svg` | National financing shares for social security and private insurance |
| `05_state_health_expenditure_share_2024_25_RE.svg` | State/UT health expenditure share, 2024–25 RE |
| `06_state_infant_mortality_rate_2023.svg` | State/UT infant mortality rate, 2023 |
| `07_state_government_hospital_beds.svg` | Absolute government hospital bed counts; source reference year unspecified |
| `08_health_spending_vs_imr_scatter.svg` | Exploratory association between 2024–25 RE budget share and 2023 IMR |

All figures are descriptive. See the relevant notebook and data dictionary for source definitions and comparability caveats.
